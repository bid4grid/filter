# Microstrip Filter Calculator (standalone)

Pure static site: no server, no database. Everything runs in the browser.

Deploy: upload this folder to any static host (Cloudflare Pages, GitHub Pages, Netlify).
Publish directory = the folder root (where index.html is). No build command.

Local test: `npx serve .` or `python3 -m http.server`, then open http://localhost:8000
Calculation tests: `node tests/run.js`

Select **Walkthrough** in the header to open the video. On mobile, use the play icon in the upper-right corner.
